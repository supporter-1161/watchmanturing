# WatchmanTuring — сторожевой пёс для ПК

Программа для Windows, которая присматривает за компьютером и пишет вам в мессенджер:

1. **Проверка состояния экрана** — заблокирован или нет.
2. **Блокировка системы** — блокирует экран Windows по команде.
3. **Режим охраны** — следит за курсором мыши и уведомляет о движении.

Канал уведомлений — **Pusk** (self-hosted, совместим с Telegram Bot API).
Если указать пустой `api_url`, программа пойдёт в обычный Telegram — оба варианта поддерживаются.

## **Требования**
- Операционная система: Windows (функционал завязан на Windows API).
- Язык программирования: Go (версия 1.24 или выше) — только для сборки.
- Развёрнутый **Pusk** (например `https://pusk.example.com`) и токен бота, созданного в нём.

---

## **Установка**

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:supporter-1161/watchmanturing.git
   cd watchmanturing
   ```

2. **Установите зависимости:**
   ```bash
   go mod tidy
   ```

3. **Скомпилируйте проект:**
   ```bash
   go build -o watchmanturing.exe main.go screen_checker.go screen_locker.go cursor_watcher.go
   ```

---

## **Настройка**

1. **Создайте бота в Pusk:**
   - Откройте панель Pusk → раздел с ботами → создайте бота.
   - Скопируйте его токен.

2. **Настройте `config.json`:**
   Скопируйте `config.exemple.json` в `config.json` и отредактируйте:
   ```json
   {
       "bot_token": "PUSK_BOT_TOKEN",
       "api_url": "https://pusk.example.com",
       "check_cursor_setting": "1000"
   }
   ```
   - `bot_token`: токен бота из Pusk.
   - `api_url`: адрес вашего Pusk (без `/bot...` на конце). Пустая строка — Telegram.
   - `check_cursor_setting`: интервал проверки курсора в миллисекундах (по умолчанию 1000 мс = 1 секунда).

> В Pusk первое сообщение чата (`/start`) приходит боту автоматически при открытии диалога,
> поэтому ID чата сохраняется в `state.json` и охрана работает сразу после перезапуска.

## **Использование**

1. **Запустите программу:**
   ```cmd
   watchmanturing.exe
   ```

2. **Откройте диалог с ботом в Pusk** (при первом открытии прилетит `/start`) — придёт меню с кнопками.

3. **Функционал кнопок:**
   - **Проверка**: проверяет, заблокирован ли экран.
   - **Блокировка**: блокирует экран Windows.
   - **Режим охраны**: включает/выключает отслеживание курсора мыши. При сдвиге курсора приходит уведомление.

Текстовые команды `Проверка`, `Блокировка`, `Режим охраны` тоже работают.

---

## **Особенности Pusk**

- Кнопки — **инлайн** (`inline_keyboard`). Обычная reply-клавиатура Telegram в Pusk не поддерживается.
- Используются методы `getMe`, `getUpdates` (long polling), `sendMessage`, `answerCallbackQuery`.
- Pusk не всегда присылает `entities` для бот-команд, поэтому `/start` распознаётся по тексту.
